# 3d-asset-library

三维素材管理器：以图搜图、C4D 素材索引、移动硬盘素材管理与 Codex 开发项目。

## 项目经验与当前进展

[项目经验手册](docs/experience/README.md)按产品、界面、数据、Windows/C4D、更新发布、测试和 AI 协作分类，供用户、网页版 ChatGPT 与 Windows Codex 共同交接。

[当前状态与下一步](docs/experience/08-current-state-and-next-steps.md)区分正式 v0.1.7、`v2-dev`、未合并功能分支和本机试用结果。下文 V14 说明属于历史原型，不代表当前 V2 的全部能力；不要据此回退正在使用的程序。

## V14 Windows 原型

> 当前基线：V14，**落地测试原型**，不是正式交付软件。

## 当前唯一目标

从 Windows 移动硬盘/项目盘上的真实素材文件夹，**只读扫描**模型、预览图及路径；尽量匹配预览；打开浏览器素材墙；Ctrl+V 粘贴截图检索；定位原素材。不要搬运、重命名或复制 `tex`，也不要与工作项目管理系统合并。

## 运行

项目必须放在 `D:\Codex\3D-Asset-Library`。

1. 双击 `01_双击_选择素材文件夹.cmd`，选择你要测试的素材目录。
2. 第一次会扫描该文件夹并生成预览索引；打开素材墙 HTML。
3. 双击 `02_快速打开上次素材库.cmd` 可直接查看上次索引。

所有主动生成的 `index.html`、`catalog.js`、缩略图和配置都保存在此项目的 `.local-data/`（被 `.gitignore` 排除）；原始模型不改动。Windows/浏览器运行时仍可能生成系统缓存，这不在脚本的文件写入控制范围内。

## 当前实际能力和限制

- 读取 `.c4d` / `.fbx` / `.obj` 等模型的文件名与路径，但**不解析原生 C4D 贴图依赖或生成 C4D 内部模型预览**。
- JPG/PNG 等预览图按同名、同目录等规则尝试匹配；不是自动识别所有情况。
- 以图搜索采用已有浏览器端图像比较策略；更多真实素材准确率仍需用户实测。
- 大文件夹扫描和本地缓存速度尚未经过用户 Windows 移动盘的实测。
- **此仓库只上传程序代码和文本说明。任何客户模型、真实贴图、项目图片、缩略图缓存都不能上传到 GitHub。**

## 开发方式

开发前先读 `AGENTS.md`；只围绕真实素材导入、预览关联、搜索和定位修复问题。不要擅自扩展成项目管理、报价、素材体检、评分或跨端同步。

## 安全检查

在任何 `git add/commit/push` 之前，先查看待提交文件清单；如果发现照片、模型、缓存、任何用户素材文件，停止并排除。
