## 预测区间（从 Windows Codex 正式开始开发起）
- **现在**：旧 v0.1.7 继续使用；现有 HTML 仅为浏览器界面预览，非新版 EXE。
- **3–7 个工作日（估计）**：最小 WebView2 桌面预览 EXE，可看新界面但不保证 C4D 工作流。
- **2–4 周（估计）**：可试用的 C4D/扫描/分类核心功能 Beta 候选，取决于 FileDrop 与 SQLite 集成顺利。
- **4–6 周（估计）**：具备原生检查更新及两次升级验证的 Beta，供日常小范围试用。
- **6–10 周或更久（估计）**：签名和完整门禁通过后的 Stable；签名资格、实机环境、回滚与旧版迁移有未知风险。
这些为资源可持续投入且依赖没有重大阻断的规划区间，**Codex 尚未自动启动、尚未产生已验证 Windows EXE**，不能把今天算作已进入开发周期。

## 新任务领取规范
1. Codex 同步原仓库并 checkout `v2-dev`，阅读 `docs/v2/PRODUCT_CONTRACT.md`、`docs/v2/EXECUTION_BOARD.md`。
2. 优先领取无阻塞的 Issue #14，用 `tdd`、`implement` 在 `v2/14-webview-host` 分支开发；Draft PR 指向 `v2-dev`，附可复现构建命令、真实 Windows 结果和失败列表。
3. ChatGPT 审查 PR 规范符合、测试证据和安全边界。功能前置 Issue 通过后才可领取后续 Issue。
4. 公共仓库只使用合成模型和占位图；任何客户模型、封面、个人路径日志不进入 GitHub。
