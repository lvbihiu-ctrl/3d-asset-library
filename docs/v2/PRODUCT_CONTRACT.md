# V2 产品与技术合同（已确认决策）

状态：V2 **开发基线**；不是任何功能已实现的证明。产品旧稳定软件 v0.1.7 不动。所有源码/任务在用户指定的**同一个公开 GitHub 仓库** `lvbihiu-ctrl/3d-asset-library` 管理，V2 在 `v2-dev` 分支开发。

## 1. 本次必须保留的工作流
1. 选择一个真实根目录，**只读**建立素材索引，不复制/修改/重命名原模型、纹理及 C4D 工程。
2. 兼容旧版扫描类型与配对语义：C4D、FBX、OBJ、BLEND、MAX、图片、HDRI、SBSAR 等；贴图目录避免当成独立素材刷屏；缺封面显示缺失，不能伪造模型关系。
3. 原 HTML 样机是视觉基线：默认浅色、可切深色，按原比例自动瀑布流（非可无限拖动的 PureRef 画布）；虚拟分类 + 真文件夹双轨；快速文字搜索、详情、选中/定位、Ctrl+V 粘贴封面、独立的 dHash 截图以图搜图入口。
4. C4D：模型卡片拖出 Windows **原生 FileDrop**，普通拖入、按住 Shift 合并入已打开场景各连续成功 3 次，不得靠网页拖拽动画冒充；不修改原模型和贴图，记录 C4D 实际版本。
5. 更新：仅在用户确认后下载/安装；启动后台检查只提示。使用 .NET + WebView2 + Velopack（待 Windows PoC 验证），真正可点击更新、安装和重启，不是假按钮。

## 2. 架构边界
- HTML/CSS/JS：负责界面显示与交互，无任意磁盘读写权限。
- .NET/C# Windows 原生宿主：只执行白名单操作：扫描、查找、封面剪贴板、拖拽、路径定位、经验证的更新器；验证 action/assetId/path，拒绝任意脚本和来自非信任页面的消息。
- SQLite + 独立封面缓存：索引、分类、封面映射、独立持久 ID；首次只支持一个主素材目录，预留多根目录键。
- 原始用户数据始终在程序版本目录外；Beta/Stable 的数据库/设置完全隔离。普通公开用户使用标准 Windows 安装及数据位置、允许选目录；当前安装在 `D:\Codex` 的旧版数据未经同意不得搬迁。
- 引用原素材，默认离线，无遥测；只有用户主动导出脱敏诊断结果。

## 3. 数据迁移
- v0.1.7 源文件 `catalog.json` / `covers.json` / `ui-categories.v1.json` / `covers/` / `thumbs/` 均不直接改写。旧路径 SHA256 ID → 新 UUID **一对一可审计**映射；迁移前和每次 DB schema 变动前完整备份，保留最近三个已验证的可恢复点。
- 同名不同路径、移动盘盘符变化、目录丢失均可能存在歧义：匹配仅在证据充分时自动执行，否则要求确认；任何未匹配项出报告，绝不猜测。
- 旧 v0.1.7 可继续应急用；V2 不与旧版双向写入同一数据文件，不让 Beta 修改 Stable。

## 4. 发行与发布
- `main`：旧版发布基线，禁止把 Preview 改动推入旧版 `desktop-updates/native/latest.json`；旧更新器只下载经 SHA256 验证的 PS1，不能直接替代 Velopack 安装器。
- `v2-dev`：新客户端集成；Issue 单任务 feature PR 由 Codex 执行，ChatGPT 审核。GitHub Actions 生成可验证的 Windows 构建与测试工件。
- 发布 Beta 可以在与 v0.1.7 并行的独立安装目录先行试用；通过全部核心验收后再尝试旧版按钮一次性迁移，失败允许可信签名安装器兜底。
- Windows 11 x64 优先；Windows 10 只在验证成功后宣传兼容；面向公众的 Stable **必须代码签名**，通过干净系统安装、C4D FileDrop/Shift、数据恢复、连续两次升级、错误回退、零客户文件泄露，最后由用户亲自批准发布。
- 仓库目前公开：在 `v2-dev` 开发不会隐藏 V2 源码；既定目标是公开 EXE，源码许可暂不定，但**保密性不可保证**。不得上传任何私人客户数据。

## 5. 发布阻断条件
任何 P0 原素材修改/数据丢失/不受信更新，P1 C4D 拖拽失败/更新失败/无法迁移/启动崩溃，或无签名 Stable 均不得发布。没有 Windows/C4D 实测结果时状态为“未测试”，不能因 CI 绿灯标为通过。

详细原型和旧版协议参考 `docs/UI_WEBVIEW2_TDD_ROLLOUT.md`、`docs/UPDATER_PROTOCOL.md`、`AGENTS.md`；与“私有仓库需先建立”等旧草案表述冲突时，以本合同和用户最新决定优先。
