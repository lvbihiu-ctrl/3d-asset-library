# Engineering issue tracker

**Provider:** GitHub Issues in `lvbihiu-ctrl/3d-asset-library`.

- Use GitHub Issues for `to-spec`, `to-tickets`, `implement`, and Code Review task linkage.
- V2 Issues must specify exact **Blocked by** Issue numbers and evidence-based acceptance criteria.
- A task is ready only when all blocking Issues have been completed and the V2 integration branch is available.
- Codex creates its own feature branch and a Draft PR against `v2-dev`; no changes to `main` until Stable is explicitly approved.
- No user/customer images or hidden paths in the public Issue or PR.
- PR submission/merge is a separate action: tool support does not mean it happened automatically.
- Do not assume a GitHub Issue's status label exists unless checked; if labels are unavailable, use the explicit Issue status field in body.

Privacy: **this repository is public**. Public visibility is unrelated to whether V2 is expressly distributed under an open-source license.
