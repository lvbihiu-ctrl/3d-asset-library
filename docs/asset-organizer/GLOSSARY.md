# 3D 素材整理器领域术语（历史归档）

**状态：2026-10-19 已归档。** 独立整理器 v0.1/v0.2 开发路线已废弃；下列术语仅是当时需求沟通的历史定义，不代表当前开发承诺或 V2 的现有功能。不得依据本术语表自动启动实现或修改 V2。

术语用于回顾两个项目的沟通，不约束数据库表结构或 API 名称。

| 术语 | 含义与边界 |
|---|---|
| 3D 素材整理器（Organizer） | **已暂停并废弃当前路线的历史项目设想**：曾计划收集、识别、归档并准备入库 |
| 3D 素材管理器 V2（Library） | 现有用于素材墙展示、查询、预览与后续 C4D 调用的**另一项目** |
| 原始素材包 | 下载或已有的一组文件，包括模型、贴图、说明、预览图等；其内部关系应尽量保持完整 |
| 旧素材 | 用户既有硬盘或旧项目目录中的文件；当前选择是以**虚拟整理、不移动原文件**为默认 |
| 新素材 | 新收到的下载包、模型或文件夹；按已确认方向可走归档流程，具体操作权限另议 |
| 素材收件箱 | 收纳拖入或监控发现的新输入的工作区概念；不代表必须复制所有文件到固定目录 |
| 物理归档 | 磁盘实际存放素材包的位置与内部层级；与标签分类区分 |
| 虚拟分类/标签 | 管理软件中的多维元信息，可以把一个素材归在多个主题下，不要求复制多个文件 |
| 展示名称 | 用户可读的分类/命名信息；与磁盘上的真实文件名不同 |
| 封面/原始预览 | 素材包提供且与目标资产能可靠关联的效果图 |
| 几何预览 | 基于实际几何体由本地程序生成的模型视图；不能承诺与最终渲染材质一致 |
| 占位图 | 没有可靠预览时显示的明确状态；不得冒充模型真实图片 |
| 疑难项/待确认区 | 无法可靠判断模型与贴图/封面关系、重复等情况，由用户批量确认 |
| 本地识别 | 使用文件名、扩展名、目录、已有图片等本地信息完成识别，无需外部 AI 服务 |
| 按需 AI | 用户可以选择让 AI 辅助分析少量疑难图片/分类；上传权限与预算规则待定 |
| 后台封面任务 | 不阻塞素材入库/搜索的异步预览生成处理过程；具体资源限制和实现待定 |
| 断点续处理 | 本地长批次被重启/断开后保留阶段记录并安全恢复的需求，不等同于网络下载续传 |
| 去重 | 识别字节相同、版本相近、素材语义相似的不同关系；曾确认双层校验及受限跳过；最终开发路线已废弃 |
| 一键入库 | 将整理器整理好的结果交给 V2 的用户动作目标；数据模型和实现协议尚未决定 |
