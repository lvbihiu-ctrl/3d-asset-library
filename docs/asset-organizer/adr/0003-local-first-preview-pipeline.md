# ADR-0003：本地识别优先，入库不等待后台封面

- 状态：**历史上已确认，但 2026-10-19 随独立整理器方案废弃而归档（非当前实施授权）**
- 日期：2026-10-18
- 所属项目：3D 素材整理器

> **归档说明（2026-10-19）**：用户在 v0.1/v0.2 试用未获得足够自动整理价值后，决定废弃独立整理器当前路线；本 ADR 保留历史原文供追溯，不创建工作项，不得据此修改 V2、原始素材或更新机制。8.3 安全恢复及 9.1 入库数据所有权均未最终确认。

## 语境

已有模型预览图可被匹配并复用；缺少预览的模型可能需要实际解析几何或打开 C4D 工程。C4D 工程可能依赖 Redshift、Octane、外部贴图和第三方插件，大批量生成所有封面既耗时又存在不确定性。

## 决策（当时的历史决策，不再推进）

1. **本地规则优先**；没有任何 AI API 配置时，基本收集、分组和索引功能也要能工作。
2. AI 仅作为**按需、可选**的疑难识别能力；并非全部素材必经步骤。
3. 素材经基础识别后优先入库、可查询，**缺失封面不阻塞索引与使用**。
4. 已有可靠预览优先；缺少封面的素材可进入后台补图流程。应区分已有预览、几何预览、明确缺失封面。
5. 不使用凭文件名生成的幻想图片冒充实际 3D 模型封面。

## 已知兼容性限制和未决范围

- OBJ/FBX 使用 Blender 或类似离线工具生成几何预览只是**技术建议**，尚未验证。
- C4D 自动载入/生成缩略图涉及版本、插件、渲染器和贴图路径，未承诺全自动无损处理。
- 后台处理并发、缓存、崩溃恢复、CPU/GPU 限额、超时策略需要原型验证。
- 云端图片上传、费用额度、用户主动授权等规则尚未确定；不能默认同意上传客户素材。

## 后果

素材管理器应容许「无封面」记录存在；封面作业失败不应删除素材记录或伪造匹配。需要单独衡量批量处理和真实 C4D 兼容性。
