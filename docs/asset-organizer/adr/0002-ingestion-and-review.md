# ADR-0002：拖入加可选监控，自动分析只请用户确认疑难项

- 状态：**历史上已确认，但 2026-10-19 随独立整理器方案废弃而归档（非当前实施授权）**
- 日期：2026-10-18
- 所属项目：3D 素材整理器

> **归档说明（2026-10-19）**：用户在 v0.1/v0.2 试用未获得足够自动整理价值后，决定废弃独立整理器当前路线；本 ADR 保留历史原文供追溯，不创建工作项，不得据此修改 V2、原始素材或更新机制。8.3 安全恢复及 9.1 入库数据所有权均未最终确认。

## 语境

输入可能是压缩包、模型、文件夹、旧硬盘目录和新下载目录。用户不愿为了入库而反复手动解压、重命名、配图与逐个分类；同时自动算法难以可靠判断所有模型、贴图和预览图的归属。

## 决策（当时的历史决策，不再推进）

1. 支持**手动拖入文件/文件夹/压缩包**的收集方式。
2. 允许用户**可选地监控指定下载目录**，而非默认监控整块硬盘。
3. 自动完成有可靠依据的分组与已有封面关联，将不能确定的情况集中呈现给用户批量确认。
4. 保留素材包来源信息，降低追踪与误分组成本。

## 不在本决策内

- 浏览器扩展式「网页一键收集」尚未被选择为当前功能。
- 文件监控具体触发逻辑、下载完成判定、压缩包密码处理尚未确定。
- 本 ADR 未授权删除、移动或重命名旧素材。
- 对异常素材的具体风险等级和自动操作权限应进一步访谈，不因目标是自动化就默认自动处理。

## 后果

需要用户可理解的待确认区；软件应能在没有 AI 的情况下处理已知、可验证的常规文件结构。入库记录必须区别「已识别」和「待确认」状态。
