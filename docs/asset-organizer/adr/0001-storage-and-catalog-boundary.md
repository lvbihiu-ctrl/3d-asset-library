# ADR-0001：旧素材虚拟整理，新素材保留完整包归档

- 状态：**已确认（用户第 2、5 轮）**
- 日期：2026-10-18
- 所属项目：3D 素材整理器（独立于管理器 V2）

## 语境

3D 素材不只是一个单独模型文件；它可能包含 C4D/FBX/OBJ、多个版本和共享贴图。简单按家具/材质目录挪动文件，会破坏工程文件与依赖文件之间的关系。与此同时用户希望管理器里能够按多种角度快速找到素材。

## 决策

1. **旧素材默认只建立索引与虚拟分类，不移动原文件。**
2. **新下载素材可以进入自动归档路径，保留原始素材包的内部文件组织。**
3. 硬盘归档和软件分类解耦：同一素材可在管理器里拥有多个标签、类别和友好展示名称。
4. 不通过为每个分类复制整个素材包实现多重分类。

## 选择它而非其他方案的原因

- 旧文件不被强制搬迁，避免路径断裂、重新复制海量历史数据。
- 完整素材包更容易保存贴图、格式、说明等彼此关联的文件。
- 多标签更适合产品广告、灯光、展示台等交叉类别。

## 重要的非决策

- 归档时是复制、移动、何时清理下载原包，尚未单独确定**操作授权**；不能因为选择了自动归档就推断可以自动删除原件。
- 实际物理根目录、命名模板、盘符重定位和磁盘占用策略未定。
- V2 最终从何处读取索引、是否共用数据库未定。

## 后果

实现需要区分**原始路径、素材包身份、展示名称与多标签**；后续必须针对贴图引用和完整性单独做测试。
